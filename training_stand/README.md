# Учебный стенд «Интернет-магазин»

Отдельное приложение для практики нагрузочного тестирования на этапах 5–8.
Работает независимо от основного backend LoadLab: свои контейнер, база и порт.

## Запуск

Из корня проекта:

```bash
docker compose -f training_stand/compose.yaml up -d --build
```

Адреса:

| Адрес | Что там |
|---|---|
| http://localhost:8082 | Магазин: поиск, корзина, заказы |
| http://localhost:8082/api/docs | Swagger API для JMeter, k6 и Python |
| http://localhost:8082/api/health | Проверка состояния |

Остановить:

```bash
docker compose -f training_stand/compose.yaml down
```

Полностью удалить данные стенда:

```bash
docker compose -f training_stand/compose.yaml down -v
```

## API

Авторизация: `POST /api/login` с почтой и паролем возвращает `token`.
Дальше токен передаётся заголовком:

```
Authorization: Bearer <token>
```

Токен действует 12 часов. В HTML-интерфейсе он хранится в cookie
`stand_token`; выход — кнопка «Выйти» или `POST /api/logout`.

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/products?q=&category=&limit=&offset=` | Поиск и список товаров |
| GET | `/api/products/{id}` | Карточка товара |
| GET | `/api/cart` | Корзина пользователя |
| POST | `/api/cart/items` | Добавить товар: `{"product_id":1,"quantity":2}` |
| PATCH | `/api/cart/items/{product_id}` | Изменить количество |
| DELETE | `/api/cart/items/{product_id}` | Удалить товар из корзины |
| POST | `/api/orders` | Оформить заказ из корзины |
| GET | `/api/orders` | Мои заказы |
| GET | `/api/orders/{id}` | Один заказ |
| POST | `/api/logout` | Выйти, удалить токен |
| POST | `/api/admin/reset` | Сбросить данные (заголовок `X-Reset-Token`) |

Токен сброса по умолчанию: `loadlab-reset`. В Docker его можно задать переменной
`STAND_RESET_TOKEN`.

## Сценарии для уроков

1. **Поиск:** гость ищет товар по названию и категории; проверяем время отклика.
2. **Вход:** получить токен, проверить 401 при неверном пароле.
3. **Корзина:** добавить товар, изменить количество, удалить.
4. **Заказ:** оформить заказ, проверить сумму и что корзина очистилась.
5. **Нагрузка:** повторить сценарий в JMeter/k6 с несколькими пользователями.
6. **Корреляция:** достать токен из ответа входа и передать в следующие запросы.
7. **Ошибки:** запрос без токена (401), несуществующий товар (404), пустая
   корзина (422), неверный токен сброса (403).

## Тесты стенда

```bash
docker compose -f training_stand/compose.yaml run --rm stand pytest -q
```

## Ограничения

- SQLite и один процесс — специально просто, чтобы стенд легко запускался.
- Заказ создаётся атомарно: параллельные запросы не порождают дубли.
- Остаток товара проверяется при добавлении в корзину и оформлении заказа;
  после заказа остаток уменьшается.
- Нет HTTPS, платежей, реальных персональных данных.
- Стенд не связан с основной базой LoadLab и не влияет на прогресс учеников.
