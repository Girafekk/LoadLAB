# Встраивание вопросов собеседований в курс

Решение: технические вопросы встроены в существующие недели 1–9. Личные вопросы
(«расскажи о своём опыте») в курс не добавляются — для них урок 9.10 и банк.

## Что сделано

В блок «Применение» 11 уроков добавлен раздел «Вопросы с собеседования»:

| Тема | Урок |
|---|---|
| Load / Stress / Spike / Soak, объёмное и отказоустойчивость | 1.5 |
| Linux: pkill/pgrep, IOPS, ядра CPU | 3.3 |
| SQL: индексы, deadlock, TRUNCATE, EXPLAIN | 3.7 |
| JMeter: Regex/JSON Extractor, Transaction Controller, Recorder | 5.6 |
| JMeter: ровно 10 RPS, pacing, think time | 6.2 |
| RPS/throughput, бизнес-метрики, p95/p99 | 7.1 |
| Java: полиморфизм, String, коллекции, final, Spring | 5.1 |
| JVM: GC-метрики, CPU-профилирование, циклы ссылок | 9.1 |
| Kafka: партиции, retention, lag | 9.3 |
| Kubernetes: sidecar, Ingress/Egress, limits, ёмкость | 9.4 |
| Заглушки: WireMock, fixedDelay, отчёт | 9.9 |

Плюс отдельный урок **9.11** «SQL, Kubernetes и JMeter: разбор реальных вопросов»
для углублённых тем.

## Что было в аудите

- 978 строк, 448 вопросов, 530 утверждений/контекста.
- 90 реальных технических вопросов: 39 покрыты, 16 уточнены, 35 были пробелами.
- 55 вопросов о личном опыте — не добавляются в уроки.
- 25 реплик/обрывков и 13 дублей — не являются темами курса.
- 302 «утверждения» — это ответы и контекст, а не 302 новых урока.

Сырые строки не добавлялись дословно: иначе в курсе появились бы дубли,
противоречия и чужие проекты. Добавлены темы, формулировки и разборы.
