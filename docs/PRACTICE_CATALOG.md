# Каталог практики LoadLab

## Интерактивные тренажёры

| Тренажёр | Где | Что проверяет |
|---|---|---|
| HTTP | `/trainers` → HTTP | метод, путь, разбор ответа |
| SQL | `/trainers` → SQL | SELECT/WHERE/JOIN на учебной БД |
| Linux | `/trainers` → Linux | команды, файлы, процессы |
| Анализ результатов | `/trainers` → Анализ | поиск причины деградации по метрикам |

## JMeter-лаборатории (уроки 5.1–5.8)

1. Первый HTTP-запрос.
2. Thread Group и число пользователей.
3. Ramp-up, Loop Count, think time.
4. Header Manager и Cookie Manager.
5. Assertions и JSON Extractor.
6. CSV Data Set Config и параметризация.
7. Timers и Listeners.
8. Полный сценарий и запуск без GUI.

## Финальный проект (уроки 8.3–8.5)

- план тестирования;
- сценарий входа/поиска/корзины/заказа;
- Load и Stress прогоны;
- HTML-отчёт;
- анализ и итоговый отчёт.
