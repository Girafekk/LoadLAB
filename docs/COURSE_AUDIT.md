# Аудит курса LoadLab

Дата: 26.11.2026. Аудит существующего проекта, без переписывания с нуля.

## Что уже есть

| Компонент | Факт |
|---|---|
| Курс | 9 модулей, 71 урок, 994 блока |
| Квизы | 714 вопросов, у каждого объяснение |
| Банк собеседований | 586 approved-вопросов из 14 источников |
| Тренажёры | HTTP, SQL, Linux, анализ результатов |
| Python | 7 уроков: типы, циклы, коллекции, функции, файлы, requests, анализ |
| JMeter | 8 уроков + 3 урока итогового проекта |
| Финальный проект | план → сценарий → прогоны → анализ → отчёт |
| Собеседование | пробное интервью, разборы, банк ответов |
| Прогресс | по урокам и квизам, сохраняется в БД |

## Сильные стороны

- последовательность от IT-основ до JMeter и анализа;
- профессиональный язык без «объяснений для пятиклассника»;
- практика HTTP/SQL/Linux/анализа в браузере;
- финальный проект на локальном магазине;
- 586 вопросов с эталонными ответами и критериями;
- тёмная/светлая тема, адаптивность 320–1920.

## Слабые места

1. Нет отдельных **модульных контрольных** и **итогового экзамена** — только квизы уроков и пробное интервью.
2. Нет **словаря терминов** и поиска по материалам курса.
3. JMeter-лаборатории описаны текстом; браузерного симулятора JMeter нет.
4. Планирование мощности было раскрыто неполно — добавлен закон Литтла в урок 6.3.
5. Финальный проект сильный, но ему не хватает единого чек-листа артефактов в интерфейсе.
6. Часть P3-косметики (busy-состояния, confirm) остаётся.

## Что не делалось

- Не переписывались хорошие уроки.
- Не добавлялись декоративные кнопки.
- Не выдавались внешние требования работодателей за факты.
