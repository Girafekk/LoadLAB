# Итоговая программа курса

Модулей: 9; уроков: 71.

## 1. Введение в IT и нагрузочное тестирование
Понять, чем занимается нагрузочный тестировщик и какие бывают тесты.
1. Как делают программы: команда, роли, место тестировщика
2. Жизненный цикл разработки и тестирования: SDLC и STLC
3. Виды тестирования: функциональное и нефункциональное
4. Зачем нужно нагрузочное тестирование: цели, задачи, цена ошибки
5. Виды нагрузочных тестов: Load, Stress, Spike, Soak
6. Требования к производительности: SLA, SLO, тестовый стенд
7. Словарь нагрузочного тестировщика: пользователь, запрос, транзакция, RPS, время отклика

## 2. Клиент-серверная архитектура и сети
Понимать, что происходит между нажатием кнопки и ответом сервера.
1. Клиент и сервер: кто кого спрашивает
2. Адреса в сети: IP, DNS, порты
3. TCP и UDP: как доставляются данные
4. HTTP и HTTPS: запрос и ответ
5. Методы HTTP и коды состояния
6. Заголовки, cookies, сессии и токены
7. JSON и REST API
8. DevTools и curl: смотрим и отправляем запросы сами

## 3. Основы Linux и SQL
Уверенно выполнять базовые действия в терминале и писать простые запросы.
1. Терминал и файловая система Linux
2. Работа с файлами и логами: cat, less, head, tail, grep
3. Процессы и ресурсы: ps, top, free, df
4. Права доступа и удалённый сервер: chmod, sudo, ssh
5. Что такое база данных; SELECT и WHERE
6. Сортировка и группировка: ORDER BY, GROUP BY, агрегатные функции
7. Соединение таблиц: JOIN
8. SQL для тестировщика: подготовка и проверка тестовых данных

## 4. Python для нагрузочного тестировщика
Писать небольшие скрипты, которые экономят время тестировщика.
1. Первая программа: переменные и типы данных
2. Условия и циклы
3. Списки и словари
4. Функции и работа со строками
5. Файлы, CSV и JSON; установка библиотек
6. HTTP-запросы из Python (библиотека requests)
7. Скрипт анализа результатов теста

## 5. Apache JMeter
Собрать и запустить первый нагрузочный сценарий.
1. Что такое JMeter; установка; минимум о Java и JVM
2. Интерфейс и Test Plan: из чего состоит тест
3. Thread Group и HTTP Request: первый запрос
4. Config-элементы: HTTP Request Defaults, Header Manager, Cookie Manager
5. Переменные и CSV Data Set Config
6. Assertions и извлечение данных из ответа (JSON Extractor)
7. Timers и Listeners
8. Первый нагрузочный сценарий целиком

## 6. Практическое нагрузочное тестирование
Перейти от «умею отправить запросы» к «умею провести тест».
1. Сценарии пользователей: кого и что мы моделируем
2. Threads, Ramp-up, Loop Count, think time и pacing
3. Нагрузочная модель и профили нагрузки
4. Корреляция и параметризация
5. Подготовка к тесту: стенд, тестовые данные, чек-лист
6. Запуск без GUI, HTML-отчёт, хранение скриптов в Git
7. Проводим Load, Stress, Spike и Soak
8. Типичные ошибки при проведении тестов

## 7. Метрики, мониторинг и анализ
Читать результаты и находить причину проблем.
1. RPS, Throughput, Response Time, Error Rate
2. Среднее, медиана и перцентили: p90, p95, p99
3. Как метрики связаны между собой; точка насыщения
4. Ресурсы сервера: CPU, RAM, диск, сеть
5. Мониторинг: обзор Grafana и Prometheus, логи приложения

7. Основы k6: первый скрипт
8. JMeter и k6: сравнение и выбор инструмента

## 8. Итоговый проект и подготовка к собеседованию
Самостоятельно пройти весь путь тестировщика и подготовиться к интервью.
