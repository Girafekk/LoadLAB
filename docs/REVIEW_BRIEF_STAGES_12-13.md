# Ревью этапов 12–13: банк вопросов и пробное собеседование

Проверяйте код и тесты, а не этот документ. Запускайте команды, смотрите
ответы API и только потом ставьте вердикт.

## Что должно быть реализовано

### Этап 12. Материалы собеседований

1. Администратор загружает TXT, PDF, DOCX, PNG/JPG.
2. PDF извлекается `pypdf`, DOCX — `python-docx`, изображения — Tesseract OCR.
3. Файл сохраняется вне Git; имя на диске не используется как путь.
4. DeepSeek извлекает вопросы; при недоступном провайдере — эвристика.
5. Вопросы дедуплицируются по fingerprint, число повторов сохраняется.
6. Есть тема, сложность, уровень, статус, привязка к уроку.
7. Отчёт: всего, подтверждено, темы, покрытие уроков, пробелы, предложения.
8. Админ-страница `/admin/interview` умеет загружать, разбирать, фильтровать,
   подтверждать, отклонять, менять урок и массово подтверждать.
9. Гость получает 401, ученик — 403, неверный файл — 422.
10. Смена темы/урока не ломает отчёт.
11. У каждого вопроса есть эталонный ответ и критерии; отчёт показывает
    `answers_ready` / `answers_missing`.

### Этап 13. Пробное собеседование

1. Старт берёт только подтверждённые вопросы (5 штук).
2. Ответ принимается только владельцем собеседования.
3. AI оценивает 0–5 и даёт разбор; при сбое — локальная оценка.
4. После последнего ответа статус `completed`, итоговый балл и отчёт.
5. Чужое собеседование — 404; гость — 401; пустой ответ — 422.
6. Лимит ответов — 15 в минуту, есть `Retry-After`.
7. `/mock-interview` показывает вопрос, поле ответа, разбор и итог.

### Регрессии

- Существующие уроки, квизы, прогресс, AI Teacher, тренажёры не сломаны.
- `alembic check` не находит расхождений.
- Ключ DeepSeek не попадает в ответы, логи и снимок.

## Ручная проверка

1. Войти администратором, открыть `/admin/interview`.
2. Загрузить небольшой TXT с вопросами; нажать «Разобрать».
3. Проверить темы, привязать вопрос к уроку, подтвердить.
4. Открыть `/mock-interview`, ответить на 5 вопросов, увидеть баллы и разбор.
5. Выйти и войти учеником: `/admin/interview` — 403, чужое собеседование — 404.

## Известные ограничения

- Смысловая дедупликация не реализована: только точные повторы.
- Разбор синхронный: большой PDF задерживает запрос.
- OCR зависит от качества скриншота.
- Итоговый проект недели 8 проверяется вручную, автоматической проверки
  артефактов нет.
- Курс 9 недель / 70 уроков; неделя 9 добавлена на основе отчёта.

## Критерии приёмки

- Нет P0/P1 по загрузке, правам, изоляции собеседований и утечке ключа.
- Тесты и сборка проходят.
- Отчёт по реальным материалам воспроизводим.
- После подтверждения вопросов пробное собеседование работает end-to-end.
