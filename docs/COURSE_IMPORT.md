# Импорт курса из файла

## Форматы

TXT, MD, PDF, DOC, DOCX до 10 МБ и до 80 000 символов.

## Как работает

1. Админ открывает `/admin` → «Создать курс из файла».
2. Загружает файл. AI разбирает текст в модули, уроки и блоки.
3. Показывается предпросмотр: модули, уроки, число блоков и первые строки.
4. «Утвердить и создать» создаёт **черновик** курса; публикации нет.
5. «Отменить» удаляет серверный предпросмотр.
6. Дальше курс правится в обычной админке: название, модули, уроки, блоки, квиз.

## Ограничения

- квиз автоматически не создаётся — его добавляют в редакторе урока;
- текст отправляется AI; персональные данные загружать нельзя;
- если AI недоступен, используется локальный разбор по заголовкам;
- брошенные предпросмотры старше 24 часов удаляются фоновым janitor раз в час.

## API

- `POST /api/v1/admin/course-imports/preview` — файл → черновик.
- `POST /api/v1/admin/course-imports/{token}/approve` — создать курс.
- `DELETE /api/v1/admin/course-imports/{token}` — отменить.
- Только администратор, CSRF через `Origin`.
