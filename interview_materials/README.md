# Материалы собеседований

Сюда складывайте файлы с вопросами и заметками с собеседований на позицию
Junior Load Tester / нагрузочный тестировщик.

Поддерживаемые форматы на этапе 12:

- PDF (текстовый слой);
- DOCX;
- TXT;
- PNG/JPG со скриншотами вопросов (потребуется OCR).

Правила:

- один файл — один источник (собеседование, вакансия, конспект);
- не добавляйте паспортные данные, телефоны и другие персональные сведения;
- файлы не попадают в Git: папка исключена, кроме этого README;
- после загрузки через интерфейс платформа извлечёт вопросы, объединит дубли,
  определит темы и сложность и предложит привязку к урокам.

Структура курса уже зафиксирована в `CURRICULUM.md` (9 недель, 70 уроков).
Файлы не перестраивают её автоматически. Они нужны, чтобы:

1. проверить, какие реальные вопросы уже покрыты уроками;
2. найти пробелы и предложить дополнительные темы;
3. пополнить банк вопросов и квизы;
4. собрать пробное собеседование этапа 13.

Любое изменение программы выполняется только после подтверждения администратором.
